# 发表情包（qqbot_sticker）

## 先记住

- **插件已经会自动配图**：每次回复有一定概率（默认 20%）在你的文字发出后自动补一张表情包（按回复情绪挑，单独一条消息）。你**不用**为了配图去调用工具——那样会多走一轮、浪费 token。
- 只有在**想发某种特定表情包**时才调用，例如有人说「来张猫猫」「发个熊猫头」，或你只想用一张图代替回复。
- 发完不要再说「已发送表情包」「（附图）」之类的话，也不要描述这张图——真人群友就是默默甩图。
- 绝不要自己画 / 生成表情包。

## 按标签直接发（最省事）

```json
{"action":"send","tag":"猫猫"}
{"action":"send","tag":"大笑"}
```

`tag` 可以是情绪或标签：在所有带这个标签的表情包里**均匀随机**挑一张（本群 6 小时内发过的会尽量避开）。精确匹配不到时会模糊匹配。

常用情绪：开心 大笑 喜欢 得意 赞同 疑惑 无语 震惊 害怕 难过 哭 生气 嫌弃 委屈 害羞 困 摸鱼 打招呼 晚安 加油 谢谢 嘲讽。

不确定库里有哪些标签时先查：

```json
{"action":"tags"}
```

## 其他用法

- `{"action":"send","emotion":"得意","query":"甘城猫猫"}`：按情绪 + 关键词模糊挑。
- `{"action":"send","id":"ABC123"}`：发指定的一张（id 来自 search）。
- `{"action":"search","query":"猫"}`：列出匹配的表情包。
- `{"action":"add_url","url":"https://..."}`：把网上找到的表情包收进库（当晚统一打标签，不是表情包的会被清掉；库满时拒收）。
- `{"action":"harvest","query":"猫猫表情包"}`：仅主人，去网上搜一批（同样夜间打标签后才能用）。

## 表情包库怎么维护（不用你操心，被问到时能解释）

- 上限 500 张；**满了就不再新增**（群友新发的也不收）。
- 每两周换一波：按「最近最少使用」踢掉最多 100 张（只踢到能腾出位置为止），再去网上搜新的补上。小喵发过、群友发过都算「使用」。
- 打标签（视觉模型识别情绪/标签）只在每天深夜睡觉时间统一做，省 token；所以新收的表情包要第二天才能用。
